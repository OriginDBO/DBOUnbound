## 🌐 What is DBO Neo-Verse?

**DBO Neo-Verse** is a private Dragon Ball Online server project — a passion-driven effort to bring back a game that deserves to exist, built by people who genuinely care about getting it right.

We're not a large organization. We're a small, focused team working with intention, building things carefully and deliberately. Every system, every line of code, every piece of content is made with the players in mind — because that's the only reason any of this is worth doing.

This project started from the publicly available **DBOGLOBAL** codebase and has grown into something entirely our own: a custom-built server with its own direction, its own pipeline, and its own standards.

We don't chase hype. We build.

---

## 🎯 What We're Building

The DBO private server scene has seen a lot of promises and very little delivery. We're not here to make promises — we're here to build something real.

**DBO Neo-Verse** is a full private server experience targeting the **DBO KR 2.0 client**, with a development focus on:

- 🥋 **Custom skills** across all classes — new animations, effects, and audio
- 🏃 **New character animations** — fly idle, fast fly, dash, emotes, and more
- 👹 **Original bosses** — hand-crafted animation sets and unique skill rosters
- 📦 **In-house content pipeline** — built and refined entirely by our team
- ⚙️ **A stable, maintainable codebase** — developed with full version control and long-term structure in mind

This isn't a quick launch. It's a proper project, done properly.
